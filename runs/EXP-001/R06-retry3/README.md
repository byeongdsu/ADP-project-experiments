다음은 동일한 정지 pose(x,y,yaw)를 저장·고정하고 컨트롤러를 끈 상태에서 초기화한 뒤 같은 순서로 시작하여 0.75를 별도 실행 2~3회 반복하는 것이다. seed=2026만으로 차량 초기 pose가 같아지는 것은 아니다. 현재 파라미터를 이번 분석에서 변경하지 않았다.
