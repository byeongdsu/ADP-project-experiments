# EXP-002 — PP / PF / 장애물 없음

기본 속도 탐색과 EXP-001(GT) 대비 비교 분석을 완료했다. 현재 PP 튜닝은 보류하고, 다음 EXP-003~004의 기본 관찰을 먼저 진행한다.

- [전체 결과와 결론](SUMMARY.md)
- [EXP-001 대 EXP-002 비교 보고서](../../analyses/EXP-001-vs-002/REPORT.md)
- [PF 측위 및 실제 추종 분석 방법](../../analyses/EXP-002/REPORT.md)
- [PF 초기화 문제와 정비 기록](../../configs/pf_initialization_validation/README.md)

R01은 초기 측위 실패로 보존하며, 시작 prior 적용 후의 R01-retry1부터 정상 초기화 조건의 주행을 평가했다. 초기화 이후 0.25~0.75는 각각3랩 무충돌,0.85는 첫 랩 충돌,추가 탐색0.80은1랩 통과 직후 충돌했다. 현재 설정 배율은0.80이며 다음 실험의 기본값으로 자동 승계하지 않는다.
