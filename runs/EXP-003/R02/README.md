# EXP-003/R02 — PP / GT / 0.25 / 장애물 2개

상태: 장애물 앞 정지로 목표 3랩 미완료. 결과 JSON 0랩, 충돌 0회, teleport 0회. 사용자 관찰: 장애물 앞에서 멈춤.

bag에서 GT 정지 위치 (-3.481102, 5.843970), 장애물 중심 (-3.893300, 2.730877), (-3.308139, 5.125269) 확인. 가까운 중심까지 약 0.739m(표면 간격 아님). 주행 후반 /drive.speed=0인 반면 /local_waypoints 첫 목표속도는 약 1.288m/s. 명령 자체의 정지이며 충돌 정지는 관찰되지 않았다.

원인 후보: TRAILING 간격 제어 또는 헤딩 감속 등 컨트롤러 분기. /state, /perception/obstacles, /trailing/gap_data 미기록으로 분기 확정 불가. 소스에서 FTG fallback은 ftg_disabled=True. 파라미터와 소스는 변경하지 않았다. 다음 원인 확인 기록에 해당 진단 토픽을 추가한다.
