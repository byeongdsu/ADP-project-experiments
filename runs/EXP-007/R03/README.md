# EXP-007/R03 — TLN / PF / 장애물 1개 / 속도 배율 0.25

실행 결과: 0랩, 벽 충돌 1회, 장애물 충돌 0회. PF 출발 검사 통과(위치 약1.53cm, 방향0.0618도).

- 맵 hyhall12, seed2026, 장애물 1개, 현재 장애물 크기 설정 0.30m
- 모델 TLN_aug.keras, mapping=false, pose_source=pf
- TLN 기본 범위 3.0~6.5m/s 대비 배율 0.25
- v_min=0.75, v_max=1.625 m/s. 나머지 추론 설정은 tln_params.yaml에 고정.
- /speed_scaler의 global_limit은 TLN 속도를 제어하지 않음.
- 공유 launch 기본값과 컨트롤러 소스는 변경하지 않음.
- 시작 1→3→4→2, 종료 1→2→3→4.
- 출발 전 PF 검사. 실제 속도는 GT odometry로 측정.
- 실제 장애물 배치는 /sim/obstacles 및 markers로 대조. 원본 bag 로컬 보존.
- 장애물 1개 조건끼리 속도 비교. R01은 장애물 2개였음.

## 출발 충돌 확인

첫 /drive 수신 후 약1.617초에 첫 wall 이벤트. 결과JSON t=0.390초는 scorer 기준이므로 구분한다.
충돌 전 명령 속도 약0.763~1.324m/s, 조향 +0.0255~+0.2608rad.
초기 GT (10.832,-0.502), yaw0.365rad에서 (11.797,0.387) 부근 벽 충돌.
장애물 1개는 (3.499,-0.610)에 있어 이번 충돌과 위치가 다름.
저속에서도 출발 구간 벽 충돌 확인. 정확한 원인은 미확정이며 속도만 원인으로 단정하지 않는다.
명령 속도는 설정 범위와 부합하지만 bag에 /parameter_events가 없어 런타임 전체 파라미터 직접 검증은 불가.

## R01·기준 경로와 출발 궤적 대조

start_comparison.png 및 start_comparison.json 참조. bag 수신시각 기준.
두 실행 모두 GT 출발 pose (10.832046,-0.502110), yaw0.365244rad, 속도0으로 동일.
R01(기본속도/장애물2개)은 출발 코너 통과, R03(0.25배/장애물1개)은 벽 충돌.
두 실행 모두 출발 구간에서 기준 경로보다 좌측으로 벌어짐.
x≈11.75m에서 R01 y0.215/yaw51.01도/경로거리0.185m, R03 y0.296/yaw54.56도/경로거리0.247m.
R03이 이 위치에서 약8cm 더 +y측이며 기준 경로와의 거리도 약6cm 큼.
두 실행에서 양의 조향과 yaw증가가 일치하여 단순 조향 부호 반전 증거는 없음.
단, 기준 경로는 TLN이 직접 따르는 목표가 아니므로 거리는 대조용.
장애물 개수·배치와 첫 조향 명령도 달라 속도만의 인과효과로 해석 불가.
저속에서 회전 궤적이 달라진 원인은 미확정. 입력 scan·모델출력 및 차량 동역학 기여를 구분하려면 추가 대조가 필요.
사용자 계획대로 후속 속도 조건에서도 장애물1개·seed·모델·조향 설정 유지. 파라미터 추가 변경이나 자동실행 없음.
