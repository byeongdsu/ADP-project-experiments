### 원인 가설과 한계

코너안쪽 편향된 진입/조향으로 차체가 안쪽 벽에 닿은 설명이 궤적과 부합.
속도 명령이 충돌직전에도2m/s수준이고 정지하지 않음. 현재 TLN에는 명시적 경로추종 lookahead나 안전거리 기반 정지 로직이 없음.
속도 매핑을 변경해도 모델 조향 출력은 그대로 사용하므로 학습된 속도·조향 조합과 실제 동역학의 불일치가 가능한 후보이나, 학습자료/원시출력 검증 전 확정 불가.
PF 오차는 충돌시 약0.180m이지만 TLN은PF를 구독하지 않아 직접 조향원인으로 연결할 근거 없음.
새 장애물 배치는 충돌약0.243초 전에 수신됨. 이미0.5초전부터 안쪽편향이 있어 새배치만 원인이라고 단정할 수 없고, 새배치가 scan/출력에 준 영향도 배제 못함.
조향 EMA 지연, 모델출력 민감도, 차량동역학 기여는 분리되지 않음. 다른 파라미터 변경 없이 후속속도조건을 동일장애물1개에서 비교.
