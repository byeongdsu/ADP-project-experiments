### 차체여유 및 충돌판정 한계

현재설치sim_params.yaml의차량length0.58,width0.2032와장애물0.30m정사각형으로근사사각형계산.
R08통과최소사각형거리약2.4cm로여유가작음. retry는충돌판정전종료해통과최소여유와직접비교불가.
retry마지막GT사각형거리는약16.8cm로계산되어이근사사각형접촉과충돌이벤트는일치하지않음.
소스base_classes.py의check_ttc는scan기반ttc_thresh0.005초,static_beams에따라obstacle/wall분류. 직접사각형교차검사가아님.
장애물raycast는차량state기준전방0.27m레이저위치사용. 현재설치폭과코드는bag내부차량상태의직접계측이아니며GT/scan수신시각비동기한계존재.
따라서사각형간격은참고계산이며실제충돌여유/판정오류를단정하지않음. 기존기록의장애물충돌은시뮬레이터이벤트분류를뜻함.

결론: 동일배치에서진입속도와조향위상차이가다른궤적을만들고,통과실행도여유가작아결과가민감할가능성. EMA0.5의강건개선입증안됨.
권고: 추가EMA탐색보다진입속도영향검증. 다음실행시EMA0.5/가중치0.65를유지하고속도범위만0.50배(1.5~3.25)로변경하는조건을후보로제안. R04는EMA0.7이므로직접동일설정대조가아님. 이번분석중실행설정수정없음.
